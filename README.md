🤖 AI Personal Assistant

An AI-powered personal assistant built with Python, Flask, Google Gemini API, and RAG (Retrieval-Augmented Generation).

🚀 Features
🤖 AI Personal Assistant
💬 Ask questions and get AI-generated responses
🧠 Google Gemini API integration
📚 RAG pipeline for document-based question answering
📄 Document retrieval and contextual responses
✉️ Email summarization
🌐 Flask web application
🎨 HTML & CSS frontend
🔐 Secure API key management using .env
⚡ REST API endpoints
